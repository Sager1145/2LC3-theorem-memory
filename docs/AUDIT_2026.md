## 具体边界与数据问题

- **A1.1（16019）：** 页面文字说明为模拟考试隐藏预载列表；菜单项点击后确实返回 “Not available. ❌”。正文列出的编号定理均是证明任务，不作为该 notebook 的预载证据。
- **Ex2.4（16014）：** 正文安排证明蕴含相关定理，弹窗实际只列 Equality 及截至合取的四个命题逻辑模块，共 63 条。正文不能替代弹窗。
- **Ex3.1（16022）：** 正文要求重新证明 “Successor”，并说明该版本此处不可用；弹窗只含 Equality 与 `Week3.Homework-6_Nat-sucInd_SOL` 的 12 条。这是排除正文题的另一个直接例子。
- **H5（16018）：** 弹窗中的模块名是带斜线的 `PropLogic/LADM-Basic`。导入器的模块名解析已修复；当前题库中该来源的 106 条声明均保留此 `section`。本审计索引也按原文保留模块名，并独立记录 `kind`、名称、编号、原文和行号，不以题库的公式合并结果代替弹窗证据。
- **课程范围：** 2026 主页只指出 Avenue 内的 notebook 链接；公开端口核查不能证明何时向学生发布，也不能排除以后新增 notebook。16030–16120 本次均拒绝连接，因此没有从这些端口虚构条目。

本审计的新增原文位于 [`research/preloaded/raw2026-extra/`](../research/preloaded/raw2026-extra/)；它们与原有 21 份捕获共同构成 JSON 中的 28 份弹窗来源。网站导入器现已处理全部 28 份，仍以弹窗声明为收录依据。
