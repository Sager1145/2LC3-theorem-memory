## 没有执行，不能视作通过

本运行环境浏览器禁止导航到本地 HTTP 和 file 地址，故采用 `page.set_content()` 运行真实 UI，并用内存 Storage 替身测试读写协议。**未在真实 GitHub Pages 地址进行线上部署测试；未验证原生浏览器跨关闭持久化；未验证 Service Worker 首次安装、离线和更新。** 没有用户仓库创建、提交或 Pages 设置变更。

没有在线运行 CalcCheck，因此“支持 CalcCheck 风格符号输入”不代表使用相同的完整证明引擎。复杂量词、替换及命令的任意等价变形仍是保守匹配。

## 实际部署后需复验

打开正式 HTTPS 地址，练错一题后刷新或关闭重开，确认错题与手选范围仍在；退出一半关卡后恢复；导出备份并在另一个浏览器确认导入；检查中文和数学符号；在首次完整加载后切换离线；修改版本后验证资源更新。然后才可把这些环境项目记为已验收。
